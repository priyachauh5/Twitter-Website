# 🐦 Twitter Clone

A responsive social media web application inspired by Twitter, built using **HTML, CSS, JavaScript, and Material UI**. The project focuses on recreating a modern social media interface with interactive components, responsive layouts, and a clean user experience.

## 🚀 Features

- 🏠 Twitter-inspired home feed
- 👤 User profile interface
- 📝 Post/tweet creation interface
- ❤️ Like and interaction elements
- 💬 Comment/reply interface
- 🔄 Retweet/repost functionality
- 🔍 Search interface
- 📱 Responsive design
- 🎨 Material UI components and icons
- ⚡ Interactive frontend using JavaScript

## 🛠️ Tech Stack

- **HTML5** – Semantic page structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – Frontend functionality and interactions
- **Material UI** – UI components and icons
